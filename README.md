# note.daiyongkim.com

브라우저에서 바로 도는 파이썬 연습장. **설치할 게 없다** — 그게 전부다.

책이나 튜토리얼을 따라가다 코드 한 조각을 돌려보고 싶을 때, 프로젝트를 만들고
런타임을 깔고 하는 게 번거로워서 만들었다. 열면 바로 친다.

## 어떻게 도는가

[Pyodide](https://pyodide.org) — CPython 을 WebAssembly 로 컴파일한 것. **진짜
파이썬이 브라우저 안에서 돈다.** 서버가 없다.

그래서:
- 남의 코드를 서버에서 실행하는 문제 자체가 없다. 샌드박스를 고민할 필요가 없다
- 호스팅이 정적이라 비용이 0이고 GitHub Pages 로 끝난다
- 오프라인에서도 (한 번 받아두면) 돈다

대가는 첫 로딩에 런타임을 받는 것 하나다. 그래서 페이지는 즉시 뜨고 런타임은
뒤에서 받는다 — 다 받기 전에 실행을 누르면 기다렸다가 실행한다.

## 에디터

textarea 하나에 **색칠한 `<pre>` 를 뒤에 깔았다.** CodeMirror 를 얹으면 이 전부를
공짜로 얻지만 번들이 붙고, "설치할 게 없다"가 이 사이트의 요점이라 로딩에 붙는 것도
최소로 둔다. 대신 **파이썬에서 없으면 못 쓰는 것들**만 손으로 넣었다:

| 키 | 동작 |
|---|---|
| `Tab` | 4칸. 여러 줄을 고르면 블록 들여쓰기 |
| `Shift`+`Tab` | 내어쓰기 (블록도 됨) |
| `Enter` | 앞 줄 들여쓰기 유지. `:` 로 끝나면 한 단계 더. `return`/`pass`/`break`/`continue`/`raise` 다음 줄은 한 단계 나옴 |
| `Backspace` | 들여쓰기 안에서는 4칸 단위로 지움 |
| `⌘`/`Ctrl`+`Enter` | 실행 |

실행취소를 살리려고 `document.execCommand('insertText')` 를 쓴다. 폐기 예정 API 지만
`value` 에 직접 대입하면 브라우저의 undo 스택이 끊기고, textarea 에서 그걸 살리는
다른 방법이 아직 없다.

### 문법 색칠에서 조심할 것 둘

**대안(alternation)의 순서가 전부다.** 주석과 문자열을 먼저 잡아야
`# def 는 키워드가 아니다` 나 문자열 안의 단어가 물들지 않는다. 키워드부터 치환하는
흔한 구현은 문자열 안까지 칠해서 금방 티가 난다. 삼중 따옴표를 홑따옴표보다 앞에 두는
것도 같은 이유 — 뒤에 두면 여러 줄 문자열이 짧은 문자열 두 개로 쪼개져 깨진다.

**두 겹의 글자 배치가 1px 이라도 어긋나면 색이 글자에서 밀린다.** 폰트·크기·행간·
패딩·탭폭·줄바꿈 규칙을 `.layer` 로 묶어 한 곳에서만 정하고, 스크롤도 같이 움직인다.
`white-space: pre`(자동 줄바꿈 없음)가 특히 중요하다 — 켜면 두 겹의 줄바꿈 위치가
달라져 아래로 갈수록 어긋난다.

## 안 넣은 것

- **문제/채점 시스템** — 이건 시험장이 아니라 연습장이다
- **계정·서버 저장** — 코드는 `localStorage` 에만 남는다. 기기를 옮기면 안 따라간다
- **패키지 설치 UI** — `numpy` 등 Pyodide 에 실려 있는 것만 쓸 수 있다

## 배포

`dist/` 를 GitHub Pages 로 그대로 올린다. 빌드 단계 없음.
